# 🔬 Histology Master Quiz (Vercel Ready)

Інтерактивний навчальний веб-додаток з гістології, цитології та ембріології для студентів медичних університетів та лікарів-інтернів. Створений на основі екзаменаційної бази кафедр проф. О.М. Грабового та проф. С.І. Савосько (НМУ імені О.О. Богомольця).

---

## 🚀 3 Режими навчання та тестування

1. **📋 Режим 1: Multiple Choice Test (Ідентифікація препарату/структур):**
   * Класичний іспитовий формат (4 варіанти відповіді).
   * Миттєве підсвічування правильних та помилкових варіантів.
   * Детальний розбір правильної відповіді та вичерпний аналіз кожного дистрактора.

2. **🔍 Режим 2: Text-Input Search (Активне пригадування з автодоповненням):**
   * Студент бачить лише мікрофотографію без підказок.
   * Інтерактивне поле пошуку з живим випадаючим списком автодоповнення українською та латиною.
   * Гнучка перевірка синонімів та толерантність до відмінків.

3. **🎯 Режим 3: Image Pointing (Локалізація структури на мікропрепараті):**
   * Завдання вказати конкретну клітину, волокно або шар безпосередньо на мікропрепараті.
   * Розрахунок відстані на Canvas у відсоткових координатах (працює на будь-якому розмірі екрана).
   * Зелена мітка при влучанні або анімоване золоте коло-підказка при промаху.

## 🌐 Розгортання (Деплой) на Vercel

Проект повністю оптимізовано для Vercel:
* `index.html` — коренева точка входу
* `images/` — оптимізована директорія мікрофотографій із чистими URL-безпечними назвами (12.3 MB)
* `vercel.json` — конфігурація кешування статики, безпекових заголовків та UTF-8 кодування
* `package.json` — метадані для автодетекту Vercel

### Спосіб 1: Через GitHub та веб-панель Vercel (Рекомендовано)
1. Ініціалізуйте Git-репозиторій та завантажте проект на GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: complete histology quiz app ready for Vercel"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/histology-quiz.git
   git push -u origin main
   ```
2. Перейдіть на [vercel.com](https://vercel.com) та авторизуйтеся (через GitHub).
3. Натисніть **«Add New...» $\rightarrow$ «Project»**.
4. Оберіть ваш репозиторій `histology-quiz`.
5. У розділі *Framework Preset* залиште **Other** (або Static HTML).
6. Натисніть **«Deploy»**. За 15 секунд застосунок отримає глобальний безкоштовний домен: `https://your-project.vercel.app`.

### Спосіб 2: Через командний рядок (Vercel CLI)
1. Встановіть Vercel CLI (якщо ще не встановлено):
   ```bash
   npm i -g vercel
   ```
2. У папці проекту виконайте команду деплою:
   ```bash
   vercel
   ```
3. Для фінального релізу в production:
   ```bash
   vercel --prod
   ```

## 💻 Локальний запуск (Local Preview)

Відкрийте файл `index.html` прямо у вашому браузері:
```bash
start index.html
```
або запустіть локальний сервер:
```bash
npx serve .
```
Додаток буде доступний за адресою `http://localhost:3000`.
